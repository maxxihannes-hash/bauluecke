    Entwurf teilen

    Der Code enthält den ganzen Entwurf: Lücke, Nachbarn, Fassade und Grundriss. Kopiere ihn in dein Portfolio oder in den Kursordner, oder füge einen Code ein und lade ihn.

    So arbeitest du

    • Lücke eingeben: Links unter „Baulücke“ und „Nachbarn“ die Maße deiner Lücke eintragen, so wie auf Bogen C notiert. Geschätzte Werte später im Portfolio mit ≈ kennzeichnen.
    • Fassade gestalten: Unter „Neubau“ Geschosse, Achsen, Dach und Material festlegen. Dann im Baukasten ein Modul wählen und auf ein Feld der Fassade tippen. Ein zweiter Tipp mit demselben Modul macht das Feld wieder zur Wand.
    • Grundriss zeichnen: Im Grundriss Wände durch Ziehen setzen, Fenster und Türen auf eine Wand tippen, Treppen als Rechteck aufziehen, Möbel einsetzen und mit „Drehen“ ausrichten. Die Öffnungen der Straßenseite kommen automatisch aus dem Erdgeschoss der Fassade.
    • Prüfen: Rechts stehen Kennwerte und Fragen an den Entwurf, zum Beispiel wie die Traufhöhe an die Nachbarn anschließt. Sie sind keine Bewertung, sondern Anlass zum Begründen.
    • Festhalten: „Bild speichern“ legt die Zeichnung in hoher Auflösung ab. „Entwurf teilen“ erzeugt einen Code, mit dem der Stand später weiterbearbeitet werden kann.
